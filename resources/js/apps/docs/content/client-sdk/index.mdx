# Client SDK (`react-ota-client`)

[`react-ota-client`](https://github.com/AbdoPrDZ/react-ota-client) adds over-the-air JavaScript bundle
updates to a **bare React Native app on Android**. A device ships one JS bundle inside the APK; this package
replaces it at runtime — no app store release, no new APK.

<Callout type="info" title="Building with Expo?">
Expo apps use a different client, [`expo-ota-client`](/expo-sdk), with Expo's own `expo-updates` as the
engine (Android and iOS). Never install both in one app.
</Callout>

<Callout type="info" title="Renamed in 1.5.0">
The npm package was called `ota-client` up to 1.4.x. When upgrading, change the dependency name and every
`from "ota-client"` import to `react-ota-client`.
</Callout>

## What you get

- **Native engine** (Kotlin, Ktor + commons-compress), autolinked into your app.
- **Typed JS API** (`OtaClient`) and ready-made React components.
- **CLI** to build the bundle that ships in the APK and the OTA archive you upload.
- **Automatic rollback** so a bad bundle reverts itself.

## Three ways in

```tsx
// 1. Declarative: wrap your root.
<OTAProvider config={{ apiBaseUrl, apiVersion, apiKey }}>
  <App />
</OTAProvider>

// 2. Hooks: keep your own UI.
const { status, check, progress, downloadAndInstall } = useOTA();

// 3. Imperative: no React at all.
await OtaClient.checkUpdate();
await OtaClient.downloadAndInstall();
```
