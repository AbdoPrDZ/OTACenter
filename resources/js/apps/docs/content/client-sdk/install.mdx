# Install

## Requirements

| | |
| --- | --- |
| React Native | 0.71+ (tested on 0.85, New Architecture enabled) |
| Android | minSdk 24, compileSdk 35+ |
| AGP / Kotlin | 8.12 / 2.1.20 (inherited from the host project) |
| Node | 18+ for the CLI |

## Step 1 — Install the package

From npm:

```bash
npm install ota-client
# or
yarn add ota-client
```

From GitHub — before the package is on the registry, or to pin a revision:

```bash
# repo name is react-ota-client, npm name is ota-client
npm install github:AbdoPrDZ/react-ota-client

# pin a tag or commit in anything you deploy (not a branch)
npm install github:AbdoPrDZ/react-ota-client#v1.0.0
```

## Step 2 — Verify autolinking

```bash
npx react-native config | grep ota-client
```

If it does not appear, rebuild `android/app` so Gradle can link the new module.

## Step 3 — Run the doctor

```bash
npx ota-client doctor
```

It checks the host project is wired up to receive OTA updates and prints anything missing.

<Callout type="warning" title="Android only">
The engine is a Kotlin module. On iOS every API rejects with `OtaUnsupportedPlatformError` and the
components render your app untouched, so the same code is safe to ship on both platforms.
</Callout>
