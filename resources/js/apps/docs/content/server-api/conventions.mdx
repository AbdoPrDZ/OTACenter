# Conventions

## Response envelope

Every admin response shares the same shape:

```jsonc
{
  "success": true,
  "message": "Items retrieved successfully",
  "items": [ /* … */ ],       // list endpoints
  "itemsCount": 12,
  "pagesCount": 2,
  "page": 1
}
```

- Single-resource endpoints use `"item"` instead of `items`.
- On failure, `success` is `false`, `message` explains why, and `errors` maps field → message.

## List parameters

| Parameter | Meaning |
|-----------|---------|
| `page` | 1-based page (default 1). |
| `pageSize` | Rows per page. **Required, ≥ 5.** |
| `search` | Free-text across filterable columns. |
| `sort[field]` | `asc` or `desc`. |
| `filter[field]` | Per-column `like` filter. |

<Callout type="warning" title="pageSize is mandatory">
Omitting `pageSize` makes the server fall back to the total row count (a full load). Always send it.
</Callout>

## Errors

| Status | Meaning |
|--------|---------|
| `400` | Validation failed (see `errors`). |
| `401` | Not authenticated. |
| `403` | Authenticated but missing a permission / role. |
| `404` | Not found (or not visible to you). |
| `419` | CSRF token expired — the SPA reloads. |

## Data types

- Dates are ISO-8601 strings.
- `File` primary keys are **strings** (`name`), not numbers.
- Relations are returned eagerly when the endpoint loads them (e.g. a user's `domains`).
