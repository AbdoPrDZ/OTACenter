# Your first release

By the end of this page you will have a live app with an uploaded bundle, scoped to a domain, ready for
a device to pick up.

## Sign in

1. Open `http://localhost:8000/dashboard`.
2. Sign in with the `APP_SUPER_ADMIN_LOGIN` / `APP_SUPER_ADMIN_PASSWORD` you configured.

## Create the app

<Steps>
<Step title="Open Apps → Add app">

Fill in **Name**, **Package name** (e.g. `com.example.myapp`), **Summary** and **Description**, and upload
a **logo**.

</Step>
<Step title="Save">

You land on the app's detail page. It has **Details** and **Statistics** tabs.

</Step>
</Steps>

## Add a version

<Steps>
<Step title="Open the app → Add version">

Pick the **Client**: *React Native* (`react-ota-client`) or *Expo* (`expo-ota-client`). Give the version a
**Name** (e.g. `1.0.0`; for Expo it must equal the app's `runtimeVersion`) and an **API key** (any strong
string — the client sends it as `API-KEY`). Write a **changelog** and choose the **APK** file (optional for
Expo).

</Step>
<Step title="Save">

The version page lists its **Bundles** and shows a Status badge.

</Step>
</Steps>

## Upload a bundle

<Steps>
<Step title="Build the OTA archive">

In a bare React Native project:

```bash
npx react-ota-client release -o release
```

This produces `release/<name>-<runtimeVersion>-<version>.tar.gz` (bundle + `manifest.json`).

In an Expo project, `npx expo-ota-client release` builds a zip of `npx expo export` — or skip this step
and the next, and let `npx expo-ota-client publish` upload it for you (see [Expo SDK](/expo-sdk/publishing)).

</Step>
<Step title="Open the version → Add bundle">

Give the bundle a **name** (usually the same version string) and upload the archive.

</Step>
<Step title="Activate it">

In the version's bundle list, **Activate** makes the bundle the one every device receives
(`versions.latest_id`). **Demo** offers it to testers only — see [Demo releases](/guides/demo-releases).

</Step>
</Steps>

## Scope access with a domain

<Steps>
<Step title="Create a domain">

Go to **Domains → Add domain**, give it a name and description.

</Step>
<Step title="Bind the app">

On the domain (or the app's **Details** tab), bind the app to the domain.

</Step>
<Step title="Bind a user">

Open a **User**, and on the **Domains** tab bind the same domain. A user sees the app when one of their
domains is bound to it.

</Step>
</Steps>

## What's next

Wire the mobile app to the server: continue to the [Client SDK](/client-sdk) for a bare React Native app,
starting with [Install](/client-sdk/install), or to the [Expo SDK](/expo-sdk) for an Expo app.
