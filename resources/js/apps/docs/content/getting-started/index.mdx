## What you will end up with

- OTACenter running locally with a seeded super-admin account.
- An **app** with a **version** and an uploaded **bundle**.
- A **domain** bound to the app and to a user.
- A React Native app wired to the SDK that pulls the bundle over the air.

## Before you start

Make sure your machine meets the [requirements](/getting-started/requirements). You will need a terminal,
PHP, Composer and Node.js; an LDAP server is optional for a first run because a local super-admin account
works without one.
