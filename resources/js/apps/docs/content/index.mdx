# OTACenter documentation

OTACenter is a **self-hosted Over-The-Air (OTA) distribution and management platform** for mobile and
desktop applications. Administrators publish apps, attach versioned builds, and decide — through
organizational **domains** and an internal **LDAP** directory — which users and devices receive which
updates.

It has two halves:

- **The server** (this Laravel application) stores apps, versions, bundles and files; exposes an admin
  JSON API and a device-facing OTA API (including the Expo Updates protocol); and serves the dashboard plus
  this documentation.
- **The client SDKs** let an installed app download and install a new JS bundle without a store release:
  - [`react-ota-client`](/client-sdk) for **bare React Native** apps on Android, with its own Kotlin engine
    and automatic rollback if the bundle fails to boot;
  - [`expo-ota-client`](/expo-sdk) for **Expo** apps on Android and iOS, with Expo's `expo-updates` as the
    engine.

Releases can go to everyone or first to a group of testers as **[demo releases](/guides/demo-releases)**,
then be promoted.
