# Environment variables

<Callout type="info" title="Docker reads a different file">
The container stack does **not** read `.env`. It uses `.env.docker` (from `.env.docker.example`), and a
few keys are then forced by `docker-compose.yml`. See **[Docker](/guides/docker)**.
</Callout>

## Application

| Key | Notes |
|-----|-------|
| `APP_NAME` | Display name (titles, docs). |
| `APP_ENV` | `local` / `production`. |
| `APP_KEY` | Generated by `key:generate`. |
| `APP_DEBUG` | `true` locally, `false` in production. |
| `APP_URL` | Absolute URL base (invite links). |
| `VITE_APP_URL` | Frontend HTTP base; defaults to same-origin + `/api`. |

## Database

| Key | Notes |
|-----|-------|
| `DB_CONNECTION` | `sqlite` (default), `mysql`, `pgsql`. |
| `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | for MySQL/PostgreSQL. |

## Directory (LDAP)

| Key | Default |
|-----|---------|
| `LDAP_CONNECTION` | `default` |
| `LDAP_HOST` | `127.0.0.1` |
| `LDAP_PORT` | `389` |
| `LDAP_BASE_DN` | `dc=local,dc=com` |
| `LDAP_USERNAME` | `cn=user,dc=local,dc=com` |
| `LDAP_PASSWORD` | — |
| `LDAP_TIMEOUT` | `5` |
| `LDAP_LOGIN_SUFFIX` | appended to the typed login |
| `LDAP_TLS` / `LDAP_STARTTLS` / `LDAP_SASL` | `false` |
| `LDAP_LOGGING` / `LDAP_CACHE` | `true` / `false` |

## Seeding

| Key | Notes |
|-----|-------|
| `APP_SUPER_ADMIN_LOGIN` | required by `SuperAdminSeeder` |
| `APP_SUPER_ADMIN_PASSWORD` | required by `SuperAdminSeeder` |

## Runtime services

| Key | Typical |
|-----|---------|
| `SESSION_DRIVER` | `file` |
| `CACHE_STORE` | `file` (avoid DB for local) |
| `QUEUE_CONNECTION` | `database` |
| `FILESYSTEM_DISK` | `local` |

## Expo updates

| Key | Notes |
|-----|-------|
| `OTA_EXPO_SIGNING_KEY` | path to a PEM RSA private key; when set, manifests are signed for apps that ask for it (`codeSigningCertificate`) |
| `OTA_EXPO_SIGNING_KEY_ID` | key id in the signature; default `main`, must match the app's `codeSigningKeyId` |
| `OTA_EXPO_ASSET_URL_TTL` | lifetime of the signed asset URLs, in minutes; default `1440` (one day) |

## Client CLI

| Key | Notes |
|-----|-------|
| `RELEASE_DIR` | default output for `react-ota-client release` / `apk` |
| `OTA_CLIENT_DEBUG` | print stack traces from the CLI |
| `OTA_TOKEN` | admin API token for `expo-ota-client publish` / `promote` (read on the developer machine, not the server) |
