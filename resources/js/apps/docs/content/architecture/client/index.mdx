# Client (`react-ota-client`)

The bare React Native client is a separate package:
[`github.com/AbdoPrDZ/react-ota-client`](https://github.com/AbdoPrDZ/react-ota-client), published to npm as
**`react-ota-client`** (`ota-client` up to 1.4.x). A device ships one JS bundle inside the APK; this package
replaces it at runtime.

Expo apps use [`expo-ota-client`](/expo-sdk) instead: there the engine is Expo's `expo-updates`, which talks
to OTACenter over the Expo Updates protocol, and this page's Kotlin engine is not involved.

| Layer | Responsibility |
|-------|----------------|
| **Native engine** | HTTP, streaming download, extraction, verification, staging, activation and restart. |
| **JS facade** | `OtaClient` — a typed, promise-based wrapper over the native module. |
| **React layer** | `<OTAProvider>` plus overlay/splash/configure screens and hooks. |
| **CLI** | `react-ota-client doctor \| android \| release \| apk`. |

## Platform support

- **Android** — full support. The engine targets **minSdk 24**; React Native **0.71+**.
- **iOS** — every API rejects with `OtaUnsupportedPlatformError` and the components render your app
  untouched, so the same code is safe to ship on both.
