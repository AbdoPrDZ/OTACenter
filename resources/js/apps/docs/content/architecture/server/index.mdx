# Server (Laravel)

## Responsibilities

- Store apps, versions, bundles, domains, users and files.
- Serve the admin JSON API (`/api`) and the device OTA API (`/ota-client/v1`).
- Authenticate against LDAP and enforce the permission matrix.
- Serve the four SPAs and this documentation.

## Folder map

```text
app/
  Src/                          Base Controller / Model / ValidationType
  Http/Controllers/             Admin API controllers
  Http/Controllers/OTAClient/   Device-facing endpoints
  Http/Middleware/              permission · role · rec.parent · device · file access
  Ldap/User.php                 LDAP model mapping
  Models/                       App, Version, Bundle, Domain, User, File, Device, …
  Models/Traits/Tabling.php     sort · search · filter · paginate
resources/js/apps/              home · docs · auth · dashboard
routes/web.php                  SPA shells, file serving, admin JSON API
routes/ota_client.php           Device API (/ota-client/v1)
```

## Conventions

- **Validation lives on the model** via `validationRules(ValidationType $type, ?Model $record)`.
- **Every list endpoint is one call** to `Model::tablingCollect($request, ...)`.
- **Responses are uniform** — controllers return `apiSuccessResponse` / `apiErrorResponse`.
